# NearSpace Kids

Educational outreach program from **Midwest Stratospheric Data Systems** introducing kids (and classrooms) to high-altitude balloons, atmospheric science, and near-space exploration.

## Mission

Make stratospheric research accessible, fun, and inspiring for young learners through hands-on activities, contests, and clear educational materials.

## Planned Content

- Coloring pages and activity sheets (balloons, payloads, weather, space)
- Bottle rocket / model rocket data collection kits and guides
- Simple explanations of how HABs work and what we measure
- Contest resources (coloring contests, design challenges)
- Classroom-friendly lesson ideas and printables
- Links to real flight data and imagery from MSDS launches

## Related Repositories

- [msds-website](https://github.com/Midwest-Stratospheric/msds-website) — Public site with educational pages
- [msds-data](https://github.com/Midwest-Stratospheric/msds-data) — Real atmospheric data kids can explore
- [x2griffon](https://github.com/Midwest-Stratospheric/x2griffon) — The actual payload that goes to near-space

## Events

Public launches (such as the planned Casey, IL area events) often include giveaways, coloring contests, and hands-on activities for kids.
